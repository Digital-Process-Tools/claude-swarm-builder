- `tests/test_example_validates.py`'s R06 backslash-literal-filename test is skipped on Windows: a
  literal backslash is a reserved character in every Windows filename, so the scenario it exercises
  (a real on-disk file whose name contains one) cannot be constructed there at all, not merely
  represented differently -- the prior version built the fixture through a path-joining operator
  that itself treats backslash as a separator on Windows, raising `FileNotFoundError` before the
  test's own assertion ran (#25).
