- `swarm_compile.py` creates a missing agent md as a skeleton instead of refusing: frontmatter
  (`name`, `description`, `model`, `tools`) taken straight from `swarm.json`, the compiled block
  exactly as for an existing file, and one empty heading below it per thing the human still has to
  write -- what it does with the brief, one heading per declared handback state, what it refuses.
  No prose is fabricated under any heading. `--check` reports a missing file as a finding and
  creates nothing; a second run over a created skeleton writes nothing (#29).
