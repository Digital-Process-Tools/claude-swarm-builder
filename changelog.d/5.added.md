- `scripts/swarm_doctor.py` implements R05: for every agent, `md` must resolve under `--root`,
  `md_hash` (sha256, null allowed) must match the file's contents when declared, and the file's
  size must be within `budget_bytes`. Three findings, warning level. A `md` that escapes `--root`
  (absolute, or `../`) is refused rather than read, since swarm.json is untrusted input on an
  external pull request. `--write-hashes` fills every null `md_hash` in the swarm file in place
  before the rules run, without disturbing the file's own line endings (#5).
