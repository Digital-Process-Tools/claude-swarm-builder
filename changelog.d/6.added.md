- `scripts/swarm_doctor.py` implements R06: every `scripts[].name` an agent declares must exist
  under `--root`, and every `*.py`/`*.sh` file under `scripts/` must be named by at least one
  agent. Warning level, one finding per orphan on either side. A declared name that escapes
  `--root` (absolute, or `../`) is refused rather than stat'd, since swarm.json is untrusted
  input on an external pull request; a declared name is compared byte-for-byte, never guessed
  at across a path separator or a case difference (#6).
